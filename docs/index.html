The office

Real terminals, one team

Every agent is the real CLI running in its own terminal, on its own branch. The orchestrator reads the board, delegates, reviews and merges. You watch it on a pixel-art floor, or work desk by desk in the Manager.

  • A shared hive on disk for messages, tasks and memory. Only the app commits to it.
  • Automations, schedules and an inbox for when an agent needs you.
  • Cost and runaway breakers, and a stop button that means stop.
Secrets

Agents use keys. They never see them.

An agent can read anything in its environment, so keys never go there. They stay encrypted with the app, or in 1Password.

  • Runners: commands you define, like npm test, that run with the secrets they need. The agent gets the output, with every value masked.
  • Keyed MCP servers run inside the app; agents hold only a pass.
  • APIs go through a local broker that adds the key to each request.
  • You approve a run whenever the agent changed the code it would run.
MCP

Bring the servers you already use

The app finds the MCP servers you set up for Claude Code, Claude Desktop, Cursor, Codex, Gemini CLI and Windsurf. Import one and your agents get it too. Its keys move to the encrypted store on the way in.

More than one office

Offices that work together

Pair with a colleague's office, or with one running on a server, and send each other work.

PQ

Sealed end to end

Team messages use X25519 with ML-KEM-768, signed with Ed25519. The relay sees a random mailbox and opaque bytes.

RL

Any relay

A public MQTT broker by default, ntfy, or one you run. No server of ours in between.

SV

The office as a server

A small headless build for Ubuntu or Docker. Pair it with your desktop and its orchestrator becomes a teammate.

WS

Offices in WSL

On Windows, a floor can live entirely inside a WSL distribution: agents, git and tools run in Linux.

FC

Factories

Send whole jobs to a software factory that speaks Factory MCP, an open profile of MCP, and follow them through its pipeline.

00

No analytics

Nothing phones home. Every connection the app makes is listed in the privacy notes.
